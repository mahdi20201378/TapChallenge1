# JARVIS Android

نسخه اولیه اندرویدی JARVIS با قابلیت گفت‌وگوی متنی، دریافت ورودی صوتی، پاسخ صوتی و استفاده از Gemini API Key شخصی کاربر.

## ساخت APK
با هر Push به شاخه jarvis-android، GitHub Actions به‌صورت خودکار APK دیباگ را می‌سازد و به‌عنوان Artifact ذخیره می‌کند.

## نکته
این نسخه بازنویسی اندرویدی و مستقل است؛ قابلیت‌های دسکتاپ مانند کنترل موس/کیبورد، مدیریت فایل و اتوماسیون مرورگر از نسخه PyQt6 به اندروید منتقل نشده‌اند. برای مکالمه از Gemini generateContent استفاده شده و این نسخه هنوز Gemini Live streaming نیست.
